# 📦 Docker Installation (Ubuntu / Debian)

## Step 1 – Update Packages

```bash
sudo apt update -y
```

---

## Step 2 – Search Docker Packages

```bash
sudo apt search docker
```

---

## Step 3 – Install Docker

Recommended:

```bash
sudo apt install docker.io -y
```

Alternative:

```bash
sudo apt install docker -y
```

---

## Step 4 – Verify Installation

```bash
docker --version
```

Example

```text
Docker version 28.x.x
```

---

## Step 5 – Start Docker Service

```bash
sudo systemctl start docker
```

---

## Step 6 – Enable Docker at Boot

```bash
sudo systemctl enable docker
```

---

## Step 7 – Check Docker Status

```bash
sudo systemctl status docker
```

Expected Status

```text
Active: active (running)
```

# 🖥️ Docker Desktop Installation (Windows)

## Step 1

Enable **Virtualization** from BIOS.

---

## Step 2

Open **PowerShell as Administrator**

Install WSL

```powershell
wsl --install
```

or

```powershell
wsl --install -d Ubuntu
```

Restart Windows.

---

## Step 3

Download Docker Desktop.

Official Documentation:

[https://docs.docker.com/desktop/setup/install/windows-install/](https://docs.docker.com/desktop/setup/install/windows-install/)

Install Docker Desktop and restart the system.

# 🧠 Important Concepts to Remember

* Docker is a **containerization platform**.
* An **Image** is a read-only template.
* A **Container** is a running instance of an image.
* **Dockerfile** contains instructions to build an image.
* **Docker Hub** is a public image registry.
* Containers are lightweight compared to virtual machines.
* `docker build` creates an image.
* `docker run` starts a container.
* `docker push` uploads an image to Docker Hub.
* `docker pull` downloads an image from Docker Hub.
* Containers are ephemeral unless data is stored using **volumes**.
