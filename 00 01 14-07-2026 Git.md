# Install Chocolatey

Official Website:

[Chocolatey Official Website](https://chocolatey.org/install?utm_source=chatgpt.com)

### Open PowerShell as Administrator

Run:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
```

Verify Installation:

```powershell
choco -v
```

Install Python using Chocolatey:

```powershell
choco install python -y
```

# Git Basics

## What is Git?

Git is a Version Control System (VCS).

### Uses

* Store source code
* Track changes
* Collaborate with teams
* Maintain project history
* Rollback code when required

### Repository

A repository (repo) is a location where code is stored.

Types:

* Public Repository
* Private Repository

# Linux VM Access Using SSH

Set Permissions:

```bash
chmod 400 key2.pem
```

Connect to Linux VM:

```bash
ssh -i key2.pem azureuser@20.237.248.39
```

Generic Format:

```bash
ssh -i <key-file> <username>@<public-ip>
```

# Linux Basic Commands

Check Kernel Information:

```bash
uname
```

Check Operating System Details:

```bash
cat /etc/os-release
```

Update Packages:

```bash
sudo apt update -y
```

Remove Git:

```bash
sudo apt remove git -y
```

Check Git Version:

```bash
git --version
```

Install Git:

```bash
sudo apt install git -y
```

Verify Installation:

```bash
git --version
```

# Git Configuration

Configure Username:

```bash

```

Configure Email:

```bash
git config --global user.email "atul_kamble@hotmail.com"
```

View Configuration:

```bash
git config --list
```

# Git Workflow

Check Status:

```bash
git status
```

Add File:

```bash
git add .
```

Commit Changes:

```bash
git commit -m "Added Hello World Program"
```

Pull Latest Changes:

```bash
git pull
```

Push Changes:

```bash
git push origin main
```

---

# Complete Git Lifecycle

```bash
git clone <repository-url>

cd repository

git status

git add .

git commit -m "your message"

git pull

git push origin main
```
